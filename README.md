# MediCitas - Panel Administrativo

MediCitas es un dashboard administrativo para la gestión visual de citas médicas, desarrollado como parte de una práctica de Desarrollo Web.

## Características

- Panel administrativo personalizado.
- Menú de navegación para pacientes, doctores y citas.
- Tarjetas con estadísticas generales.
- Tabla de próximas citas.
- Accesos rápidos a las principales secciones.

## Tecnologías utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
- Bootstrap 4
- SB Admin 2

## Ejecución local

El proyecto puede ejecutarse utilizando Laragon con Apache.

1. Copiar la carpeta `dashboard-medico` dentro de `C:\laragon\www`.
2. Iniciar Apache desde Laragon.
3. Abrir en el navegador:

   `http://localhost/dashboard-medico/`
